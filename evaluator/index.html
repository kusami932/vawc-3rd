Between participants

Saved state lives in this browser's localStorage under vawc-p4-revised-v1. Press reset, then open the prototype and confirm the home form is empty.

Manual checks

  1. Fresh state: no prefilled values, no evaluation links in the participant menu or footer.
  2. Recovery: run a job search with no results, use a suggested condition to remove, then Update results; the earlier results stay until Update is pressed.
  3. Wrong turn: open a notice dialog from a peripheral entry, close it, and confirm the search state is unchanged.
  4. History: use browser Back/Forward across results, details, application information and the comparison.
  5. Text size: use Accessibility → larger text, then Restore default; check the comparison and the forms.
  6. Not yet run by anyone: screen reader, Firefox/Safari, phone, 200–400% browser zoom, deployed copy.
